# Second Brain AI

> **Персональная интеллектуальная система обучения, управления знаниями и отслеживания навыков для Omarchy Linux.**

Second Brain AI объединяет ИИ-преподавателя, генератор учебных курсов, постоянную память контекста, библиотеку учебных материалов с RAG (PDF, DOCX, Markdown, C++, Python), трекер навыков, интерактивную карту знаний на React Flow, изолированную песочницу для выполнения кода и научно обоснованную систему интервального повторения SuperMemo SM-2.

---

## Ключевые возможности

1. **Постоянная память и моментальное возобновление обучения:**
   - Закройте приложение в любой момент — система сохраняет полный контекст.
   - Большая кнопка «Продолжить обучение» восстанавливает последний открытый урок и контекст беседы с ИИ.
2. **Генерация курсов и уроков с помощью ИИ:**
   - Поддержка Google Gemini API и локального Ollama.
   - Построение пошаговой дорожной карты (модули и уроки) на основе любой цели («Хочу изучить C++ с нуля», «Linux и кибербезопасность за 6 месяцев»).
   - Умная генерация уроков по требованию.
3. **Три режима использования источников:**
   - **Свободное обучение**: общие знания модели + привлечение материалов по желанию.
   - **Мои материалы + знания ИИ**: строгий приоритет загруженных книг и конспектов с цитированием страниц; дополнения ИИ маркируются отдельно.
   - **Только мои материалы**: строгое следование фактам из источников без домыслов и галлюцинаций.
4. **Библиотека материалов и RAG:**
   - Загрузка PDF, DOCX, TXT, Markdown, C++, Python, Bash.
   - Полнотекстовый поиск SQLite FTS5 и семантическое цитирование.
   - Изоляция материалов между разными курсами.
5. **Безопасная песочница кода (Linux Sandbox):**
   - Выполнение C++ (g++ 16 / C++20), Python 3.14, Bash в изолированной среде.
   - Ограничения `setrlimit` (таймаут 4 сек, память 128 МБ, защита от зависаний и переполнения).
6. **Интерактивная карта знаний (React Flow):**
   - Визуальный граф навыков с цветовой кодировкой статуса (Освоено, Изучается, Требует практики).
   - Связи зависимостей и дерево предварительных знаний.
7. **Интервальное повторение (SM-2):**
   - Алгоритм кривой забывания Эббингауза SuperMemo SM-2.
   - Автоматическое планирование повторений на главной панели.
8. **Атомарный бэкап и восстановление:**
   - Использование SQLite Online Backup API прямо из интерфейса или CLI.

## Архитектура и технологии

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS (тёмная графитовая тема), React Flow, Recharts, Lucide Icons, TanStack Query.
- **Backend:** Python 3.14, FastAPI, SQLAlchemy 2.0, Pydantic v2, Pytest.
- **База данных:** SQLite 3 (WAL mode, Foreign Keys ON, FTS5 полнотекстовый поиск).
- **ИИ-интеграция:** Google Gemini API (прямые асинхронные HTTP/JSON запросы) + Ollama Local API.
- **Окружение:** Omarchy Linux (Arch-based).

## Быстрый запуск

### Вариант 1: Запуск через скрипт (рекомендуется)
```bash
cd ~/Projects/second-brain-ai
./scripts/run_app.sh
```
Скрипт автоматически запустит backend на порту 8000, frontend на порту 5173 и будет транслировать логи в терминал.

Откройте в браузере:
- **Интерфейс приложения:** `http://127.0.0.1:5173`
- **Документация API (Swagger):** `http://127.0.0.1:8000/docs`

### Вариант 2: Запуск через ярлык Omarchy Linux
Ярлык приложения уже установлен в `~/.local/share/applications/second-brain-ai.desktop`.
Вы можете запустить приложение через меню приложений Omarchy (Walker / Fuzzel / Rofi), набрав:
`Second Brain AI`

## Резервное копирование и восстановление

### Создание резервной копии:
- Через интерфейс: «Настройки» ➔ «Создать резервную копию».
- Через CLI:
  ```bash
  ~/Projects/second-brain-ai/scripts/create_backup.sh
  ```

### Восстановление:
- Через интерфейс: выберите нужную копию в разделе «Настройки» и нажмите «Восстановить».
- Через CLI:
  ```bash
  ~/Projects/second-brain-ai/scripts/restore_backup.sh ~/Projects/second-brain-ai/data/backups/backup_ГГГГММДД_ЧЧММСС.db
  ```
