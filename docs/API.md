# Справочник API — Second Brain AI

Базовый адрес: `http://127.0.0.1:8000/api`

Интерактивная документация Swagger: `http://127.0.0.1:8000/docs`

---

## 1. Главная панель (Dashboard)

- **GET `/api/dashboard`**: возвращает сводные аналитические показатели, текущие курсы, последнюю открытую сессию, рекомендации ИИ и запланированные повторения.

## 2. Курсы (Courses)

- **GET `/api/courses`**: список курсов с расчетом прогресса (параметр `include_archived=false`).
- **POST `/api/courses`**: создание курса вручную или программно.
- **GET `/api/courses/{id}`**: детальная информация о курсе, включая модули и уроки.
- **PUT `/api/courses/{id}`**: обновление метаданных и режима обучения курса.
- **DELETE `/api/courses/{id}`**: удаление курса (каскадно удаляет связанные модули и уроки).

## 3. Уроки (Lessons)

- **GET `/api/lessons/{id}`**: просмотр урока, автоматическое обновление отметки последнего доступа (`last_accessed_at`).
- **PUT `/api/lessons/{id}`**: обновление текста и метаданных урока.
- **PUT `/api/lessons/{id}/progress`**: отметка о прохождении (`is_completed: boolean`).

## 4. Сессии и Хронометраж (Sessions)

- **GET `/api/sessions/last-active`**: возвращает контекст последнего открытого урока для функции «Продолжить обучение».
- **POST `/api/sessions/ping`**: фиксация реального времени обучения (секунды).

## 5. ИИ-Генератор и Преподаватель (AI & Tutor)

- **POST `/api/ai/generate-course`**: генерация полной дорожной карты курса по цели пользователя (Gemini / Ollama).
- **POST `/api/ai/generate-lesson`**: генерация подробного урока в Markdown.
- **POST `/api/tutor/chat`**: диалог с ИИ-преподавателем с поддержкой 3 режимов обучения и RAG-цитирования.
- **POST `/api/ai/test-connection`**: проверка соединения с активным ИИ-провайдером.

## 6. Библиотека и RAG (Documents)

- **GET `/api/documents`**: список загруженных документов.
- **POST `/api/documents/upload`**: загрузка PDF, DOCX, TXT, Markdown, C++, Python с автоматической FTS5-индексацией.
- **DELETE `/api/documents/{id}`**: удаление файла и очистка поискового индекса.
- **GET `/api/documents/search?query=...`**: полнотекстовый и семантический поиск по фрагментам.

## 7. Практика и Песочница (Practice)

- **GET `/api/practice/exercises`**: список квизов и задач по программированию.
- **POST `/api/practice/run-code`**: изолированное выполнение кода (C++, Python, Bash) в Linux sandbox с лимитами `ulimit`.
- **POST `/api/practice/submit`**: проверка решения и автоматическое планирование повторения по алгоритму SM-2.

## 8. Карта знаний и Навыки (Skills)

- **GET `/api/skills`**: список навыков со статусами и уровнями уверенности.
- **GET `/api/skills/graph`**: узлы и ребра для графа React Flow.
- **PUT `/api/skills/{id}/progress`**: обновление статуса мастерства.

## 9. Повторения (Reviews)

- **GET `/api/reviews/due`**: элементы, требующие повторения сегодня.
- **POST `/api/reviews/{id}/grade`**: выставление оценки (0-5) и пересчет интервала SM-2.

## 10. Системные настройки и Бэкап (System & Backup)

- **GET `/api/system/settings`**: текущие настройки системы.
- **PUT `/api/system/settings`**: обновление ключей API и моделей.
- **POST `/api/backup/create`**: создание атомарного снапшота SQLite.
- **POST `/api/backup/restore`**: безопасное восстановление из файла резервной копии.
