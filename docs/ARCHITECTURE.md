# Архитектура Second Brain AI

## 1. Концепция и Назначение

**Second Brain AI** — персональная интеллектуальная система обучения, управления знаниями и отслеживания навыков, спроектированная специально для настольной среды Omarchy Linux (Arch-based).

Главный принцип системы: **пользователь может начать изучение любой темы, закрыть приложение и спустя любое время вернуться к тому же уроку, сохранив весь контекст, диалоги и подтвержденные навыки.**

## 3. Модели Данных (20 Таблиц)

1. **profiles**: Профиль пользователя системы.
2. **courses**: Учебные курсы (название, цель, уровень, режим обучения).
3. **modules**: Модули внутри курса (порядок, описание).
4. **lessons**: Уроки (содержание в Markdown, время, статус прохождения, последний доступ).
5. **learning_sessions**: Сессии обучения с реальным хронометражем в секундах.
6. **conversations**: Сессии диалога с ИИ-преподавателем.
7. **messages**: Сообщения диалога с фиксацией использованных источников и RAG-цитат.
8. **documents**: Загруженные книги, конспекты, исходный код.
9. **document_chunks**: Смысловые фрагменты с привязкой к страницам и разделам.
10. **course_documents**: Привязка документов к конкретным курсам (изоляция приватных материалов).
11. **notes**: Конспекты и заметки пользователя.
12. **exercises**: Практические задания (квизы, задачи по программированию).
13. **submissions**: Попытки решения заданий с баллами и обратной связью.
14. **assessments**: Итоговые тестирования модулей.
15. **skills**: Каталог навыков (Linux, C++, Алгоритмы).
16. **skill_progress**: Подтверждённый статус и уровень уверенности (0-100%).
17. **skill_relationships**: Граф зависимостей между навыками (для React Flow).
18. **review_schedule**: Расписание интервальных повторений SM-2.
19. **settings**: Системные настройки и ключи API.
20. **ai_usage**: Учет расхода токенов и запросов к моделям.

## 4. Три Режима Использования Источников

- **Режим A: «Свободное обучение» (Free Learning)**: Модель отвечает на основе общих знаний и привлекает библиотеку по мере необходимости.
- **Режим B: «Мои материалы + знания ИИ» (Materials Priority)**: Ответ строится в первую очередь на фрагментах из пользовательских документов с точными ссылками, а дополнения модели маркируются блоком `> [!NOTE] Дополнение ИИ`.
- **Режим C: «Только мои материалы» (Strictly Grounded)**: Ответ опирается исключительно на факты из загруженных источников. При отсутствии информации модель прямо сообщает об этом.

## 5. Безопасность и Изоляция

- Backend по умолчанию привязан строго к `127.0.0.1`.
- Запуск пользовательского кода производится в изолированной временной директории с жесткими ограничениями `setrlimit` (таймаут 4 секунды, память 128 МБ, запрет core-дампов).
- API ключи не передаются во frontend в открытом виде.
- Загружаемые документы экранируются от prompt injection (контент передается строго как справочный контекст, а не системные директивы).
